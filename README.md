# ST-Thief-Book: 酒馆助手（Tavern Helper）隐蔽摸鱼阅读与回复工具

> **仿 VS Code 著名摸鱼插件「Thief-Book」设计。**
>
> 专为办公室、宿舍及公开场合打造的 SillyTavern（酒馆）极致隐蔽交互工具。**桌面原生置顶摸鱼条是唯一阅读界面**，酒馆网页端脚本作为无界面桥接后端，负责正文过滤、流式同步与回复通道。将 AI 生成的长篇回复以**极简纯文本条**或 **VS Code 底部状态栏**形式呈现，支持整段分屏阅读、自动阅读、字号缩放、贴边自动隐藏、阅读位置记忆、边看边回与一键老板键，助你从容优雅地享受阅读！

---

## 🏗️ 架构：网页桥接 + 桌面阅读

| 端 | 职责 |
| :--- | :--- |
| **Web 脚本端**（`st-thief-book.js`，酒馆助手内运行） | 无界面桥接后端：监听消息与流式生成、白名单正文提取 + 思考黑名单剥离、整段分句状态机、经 WebSocket 同步桌面端、代发送回复 / Swipe / 中止生成；提供 ⚙️ 设置面板（过滤规则与桥接密钥配对） |
| **桌面端**（`thief_desktop_bar.py`） | 唯一阅读 UI：置顶隐蔽状态栏渲染、整段分屏翻阅、自动阅读、字号缩放、贴边隐藏、位置记忆、老板键伪装；内置 WebSocket 服务（`127.0.0.1:18899`，密钥认证 + 来源白名单） |

> 网页端**不再提供**阅读条、悬浮胶囊或画中画窗口——所有阅读交互都在桌面摸鱼条上完成，酒馆页面零侵入。

**首次配对（只需一次）：**
1. 启动桌面端后，**右键摸鱼条 → 复制桥接密钥**；
2. 酒馆脚本按钮栏点击 **⚙️ Thief设置**，将密钥粘贴到「桥接密钥」输入框，保存；
3. 看到「🟢 桌面端认证成功」提示即配对完成，密钥双方各自持久化，重启自动复用。

## ✨ 核心特性

### 1. 🕶️ 极致隐蔽的摸鱼形态
- **极简形态（Minimal Mode）**：界面纯净无冗余，仅保留正文文字与极简深色背景，移除所有徽章与多余按钮，隐藏在屏幕边缘或任务栏如同系统提示。
- **VS Code 状态栏形态**：高度仿真的开发工具状态栏设计，自带 Git 分支、楼层胶囊与进度展示，与日常编程工作区天衣无缝融合。
- **多款专业主题**：内置 `VS Code 深色`、`经典蓝条`、`终端黑客绿` 等预设风格，支持 15%~100% 透明度无级微调。

### 2. 📏 恒定高度锁定与整段分屏阅读
- **窗口高度绝对锁定**：单行模式固定 30px/36px，双行模式固定 56px/68px，无论文字多长均绝不向下撑大窗口，杜绝大弹窗暴露风险。
- **整段分屏阅读**：整条消息连成一段，按当前条宽切成若干屏——整句优先成屏，超宽才硬切，断点始终跟随条宽。点击或按快捷键时**先在消息内逐屏翻阅，读完整条才过渡到下一句**，100% 不裁切、不丢字。
- **流式生成友好**：生成中始终跟随最新一屏，生成结束自动回到首屏方便从头阅读；拖边缩放后 120ms 去抖重新分屏，阅读位置不丢失。
- **同步不打断阅读**：网页端同步刷新（如流式追加、配置变更）不会把你正在读的这一屏拽走，只有你自己翻句/翻楼时才移动阅读位置。
- **可关闭分屏**：右键菜单取消勾选“整段分屏阅读”即回到单行截断模式（超宽以 `…` 结尾），一次看完一行。

### 3. 🆕 沉浸式阅读增强（v3.6）
- **页码进度指示**：状态栏实时显示 `句序x/y 屏a/b`，整条消息读到哪一目了然。
- **字号缩放**：`Ctrl + 滚轮` 在 8~12pt 间调节正文字号，自动重新分屏并持久化，小屏远观两相宜。
- **自动阅读**：右键菜单选择每 3 / 5 / 8 秒自动翻屏；鼠标悬停、老板键伪装、AI 生成中、回复框聚焦时智能暂停，移开继续。
- **阅读位置记忆**：楼层 / 句序 / 屏偏移自动落盘，重启桌面端后自动请求网页端跳回上次读到的位置，接着读不迷路。
- **贴边自动隐藏**：开启后窗口贴近屏幕工作区边缘即收起到只剩 3px 细条，鼠标碰到边缘平滑滑出，移开 500ms 后自动收起；多显示器按所在屏工作区判定。

### 4. ↔️ 自由拉伸、Auto-fit 与多屏幕原生支持
- **边缘鼠标直接拖拽**：鼠标悬停在摸鱼条左/右边缘即可拖拽拉长或缩短窗口，文字实时重新排版，宽度自动持久化保存。
- **窄条自适应**：标准模式条宽不足 560px 时自动收起分支名与角色名，把宽度让给正文；拉宽后自动还原。
- **智能 Auto-fit（一键适应长短）**：按下 `Ctrl + ↑` 或右键菜单选择“自动适应文字长短”，系统会根据当前句子的实际字数与像素宽度，自动为窗口匹配最舒适的长度。
- **多显示器原生支持**：支持主副屏幕、不同 DPI 与跨屏虚拟坐标，在副显示器上拉伸或移动窗口时稳固跟手，绝无漂移或位置跳变。

### 5. 💬 专属小说阅读体验（用户消息过滤）
- **仅看 AI 对白与小说正文（默认开启）**：阅读时自动跳过所有用户输入楼层，新消息接收、读完自动进入下一楼、或翻楼查阅时，均直接展示连续的 AI 角色回复与正文描写。
- **自由切换显示**：可在右键菜单或设置面板中随时一键开关“显示用户消息”，兼顾纯小说沉浸与对话复盘。

### 6. 🛡️ 智能白名单正文提取 + 思考黑名单彻底剥离
- **白名单正文容器提取**：优先提取包裹在 `<content>`、`<response>`、`<dialogue>`、`<story>`、`<正文>` 等标签内的纯净正文，外层的复杂选项、元数据或变量更新自动隔离；若未检测到容器标签则自动读取全文。
- **全语法格式黑名单剥离**：彻底清除黑名单标签及其内部文本，不仅全面支持标准闭合标签（`<think>...</think>`、`[thought]...[/thought]`），亦完美兼容提示词中常见的单标签与冒号指令（如 `[system: ...]`、`<instruction: ...>`），杜绝指令泄露。

### 7. ⌨️ 双行边看边回 / 单行纯享
- **双行模式（边看边回）**：上行小说正文，下行就地嵌入紧凑回复框，打字按 `Enter` 立即回车发送并自动触发酒馆 AI 续写。
- **单行模式（极致紧凑）**：仅 30px 高度的超窄纯阅读条，最大程度减少屏幕占用。

### 8. 🕶️ 强韧常驻的一键老板键（Boss Key）
- 遇到同事或老板走近时，按下 **`Esc`** 键：0.1 秒内秒切为 `TypeScript Ready` 或 `webpack compiled successfully` 代码编译状态。
- **防误触常驻机制**：处于伪装状态时屏蔽点击翻句与滚轮动作，移动窗口不解除伪装，**必须再次显式按下 `Esc`** 才会安全退出伪装返回阅读。
- 酒馆脚本按钮栏的 **🕶️ 老板键** 按钮可远程同步切换伪装状态。

## 🚀 极速上手

### 第一步：启动桌面摸鱼条（阅读界面）
1. 双击运行项目目录下的 **`start_desktop.bat`**（或在终端运行 `python thief_desktop_bar.py`）；
2. 屏幕底部即出现摸鱼条窗口，零额外依赖、开箱即用；
3. **右键点击任意处**：呼出深色功能菜单，一键切换极简模式、单双行布局、自动阅读、贴边隐藏、透明度与黑白名单；
4. **左键点击文字**或**鼠标滚轮**即可整段分屏翻阅；双行模式下直接在下方输入框打字按 `Enter` 就地回复。

> 单实例保护：重复启动会自动退出，不会出现两条摸鱼条互抢消息。

### 第二步：导入网页桥接脚本（过滤与同步）
1. 打开 SillyTavern，进入 **酒馆助手（Tavern Helper）** -> **脚本管理**；
2. 点击 **“导入脚本”**，选择项目中的 **`st-thief-book.json`** 导入并启用；
3. 脚本按钮栏出现 **⚙️ Thief设置** 与 **🕶️ 老板键** 两个按钮；
4. 按上文「首次配对」填入桥接密钥，桌面端随即开始实时接收酒馆消息。

> 桌面同步默认开启：桌面端未启动时网页端静默重试，不产生任何弹窗打扰；启动桌面端后自动连上。

## 📁 项目文件架构

| 文件名 | 作用说明 |
| :--- | :--- |
| **`st-thief-book.json`** | **酒馆一键导入脚本包**：导入酒馆助手即启用无界面桥接后端（过滤 + 同步 + 回复通道 + 设置面板） |
| **`st-thief-book.js`** | **Web 桥接后端源码**：消息监听、黑白名单过滤引擎、整段分句状态机、WebSocket 同步与 ⚙️ 设置面板 |
| **`thief_desktop_bar.py`** | **桌面端唯一阅读 UI**：轻量、无外部依赖的置顶透明状态栏，整段分屏/自动阅读/贴边隐藏/位置记忆/老板键 |
| **`start_desktop.bat`** | **Windows 便捷启动脚本**：双击即可启动 Python 桌面端客户端 |
| **`thief_bar_config.json`** | **桌面端本地配置文件**：保存窗口尺寸、透明度、主题、字号、自动阅读及过滤配置项 |
| **`thief_bar_bridge.token`** | 桥接密钥（运行时自动生成，独立存放，不进版本库） |
| **`thief_bar_position.json`** | 阅读位置记忆（运行时自动落盘，不进版本库） |

## 💡 使用小贴士

1. **更隐蔽的摆放推荐**：
   - 开启 **极简模式** 后，将摸鱼条长度拉长至接近屏幕底边宽度，贴近 Windows 任务栏上方放置，外观与系统状态提示无异。
   - 适当将透明度设置为 **70% 或 80%**，背景融入当前工作软件窗口（如 IDE 或浏览器），既清晰易读又极大降低侧边被窥视风险。
   - 开启 **贴边自动隐藏** 后把窗口拖到屏幕边缘，平时只露 3px 细条，鼠标轻碰边缘即滑出，隐蔽性拉满。
2. **沉浸式追更**：开启 **自动阅读（每 5 秒）**，AI 生成时自动暂停、生成结束继续翻屏，配合 **阅读位置记忆**，重启后从上次那一屏接着读。
3. **提示词与思考过程过滤**：
   - 若使用的模型具有 DeepSeek 或 CoT 思考链，摸鱼条已内置预设过滤 `<think>`, `<thought>`, `<cot>`, `[system: ...]` 等思考过程。如果使用了其他自定义标签，随时打开 **右键 -> ⚙️ 设置**（或网页端 **⚙️ Thief设置**）将标签名称填入黑名单即可彻底过滤。
4. **远程酒馆**：桌面端默认仅接受本机来源连接；若酒馆部署在远端，右键菜单 **远程酒馆来源白名单…** 中添加其 Origin 后方可桥接。
