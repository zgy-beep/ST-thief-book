# ST-Thief-Book: 酒馆助手（Tavern Helper）隐蔽摸鱼阅读与回复工具

> **仿 VS Code 著名摸鱼插件「Thief-Book」设计。**
>
> 专为办公室、宿舍及公开场合打造的 SillyTavern（酒馆）极致隐蔽交互工具。**桌面原生置顶摸鱼条是唯一阅读界面**，酒馆网页端脚本作为无界面桥接后端，负责正文过滤、流式同步与回复通道。将 AI 生成的长篇回复以**极简纯文本条**或 **VS Code 底部状态栏**形式呈现，支持整段分屏阅读、自动阅读、字号缩放、贴边自动隐藏、阅读位置记忆、边看边回与一键老板键，助你从容优雅地享受阅读！

---

## 🏗️ 架构：网页桥接 + 桌面阅读

| 端 | 职责 |
| :--- | :--- |
| **Web 脚本端**（`st-thief-book.js`，酒馆助手内运行） | 无界面桥接后端：监听消息与流式生成、白名单正文提取 + 思考黑名单剥离、整段分句状态机、经 WebSocket 同步桌面端、代发送回复 / Swipe / 中止生成；在魔法棒（扩展）菜单提供 **摸鱼条** 入口（⚙️ 设置面板：过滤规则与桥接密钥配对） |
| **桌面端**（`thief_desktop_bar.py`） | 唯一阅读 UI：置顶隐蔽状态栏渲染、整段分屏翻阅、自动阅读、字号缩放、贴边隐藏、位置记忆、老板键伪装；内置 WebSocket 服务（`127.0.0.1:18899`，密钥认证 + 来源白名单） |

> 网页端**不再提供**阅读条、悬浮胶囊或画中画窗口——所有阅读交互都在桌面摸鱼条上完成，酒馆页面零侵入。

**首次配对（只需一次）：**
1. 启动桌面端后，**右键摸鱼条 → 复制桥接密钥**；
2. 酒馆**魔法棒（扩展）菜单**点击 **摸鱼条**，勾选「启用本地桌面端同步」，将密钥粘贴到「桥接密钥」输入框，保存；
3. 看到「🟢 桌面端认证成功」提示即配对完成，密钥双方各自持久化，重启自动复用。

## ✨ 核心特性

### 1. 🕶️ 极致隐蔽的摸鱼形态
- **极简形态（Minimal Mode）**：界面纯净无冗余，仅保留正文文字与极简深色背景，移除所有徽章与多余按钮，隐藏在屏幕边缘或任务栏如同系统提示。
- **VS Code 状态栏形态**：高度仿真的开发工具状态栏设计，自带 Git 分支、楼层胶囊与进度展示，与日常编程工作区天衣无缝融合。
- **主题即伪装皮**：右键菜单「主题」直接列出 16 套伪装风格（开发 / 办公 / 影音 / 系统 四组），`Alt+T` 循环切换；原来的深色/经典蓝配色已统一为深色一套，不再单独提供。支持 15%~100% 透明度无级微调。

### 2. 📏 恒定高度锁定与整段分屏阅读
- **窗口高度绝对锁定**：单行模式固定 30px/36px，双行模式固定 56px/68px，无论文字多长均绝不向下撑大窗口，杜绝大弹窗暴露风险。
- **整段分屏阅读**会按正文实际可用宽度分屏，优先在句末换屏。读完末屏再翻会进入下一楼首屏，从首屏往回翻会进入上一楼末屏。
- 新回复从首屏开始。正文继续生成、生成结束或拖动窗口边缘时，都会保留正在阅读的位置。
- 手动翻阅历史楼层时，后台渲染、流式生成和配置同步会保留当前位置。切换会话时会打开最新可读楼层的首屏。
- 在桌面设置的**阅读模式**中可选择整段分屏或逐句截断。逐句截断模式下，当前句超出正文可用宽度时以 `…` 结尾。

### 3. 🆕 沉浸式阅读增强（v3.6）
- **页码进度指示**：状态栏实时显示 `句序x/y 屏a/b`，整条消息读到哪一目了然。
- **字号缩放**：`Ctrl + 滚轮` 在 8~12pt 间调节正文字号，自动重新分屏并持久化，小屏远观两相宜。
- **自动阅读**：右键菜单选择每 3 / 5 / 8 秒自动翻屏；鼠标悬停、老板键伪装、AI 生成中、回复框聚焦时智能暂停，移开继续。
- 阅读位置会自动保存，正常退出时也会立即保存最后一次翻页。桌面重开或酒馆刷新后，同一会话会恢复到上次读到的文字位置。
- **贴边自动隐藏**：开启后窗口贴近屏幕工作区边缘即收起到只剩 3px 细条，鼠标碰到边缘平滑滑出，移开 500ms 后自动收起；多显示器按所在屏工作区判定。

### 4. ↔️ 自由拉伸、Auto-fit 与多屏幕原生支持
- 拖动结束或退出时会保存窗口位置，下次启动回到原处。贴边隐藏时会记住展开位置，副屏断开后会移回可用屏幕。
- **边缘鼠标直接拖拽**：鼠标悬停在摸鱼条左/右边缘即可拖拽拉长或缩短窗口，文字实时重新排版，宽度自动持久化保存。
- **窄条自适应**：标准模式条宽不足 560px 时自动收起分支名与角色名，把宽度让给正文；拉宽后自动还原。
- 按 `Ctrl + ↑` 或在右键菜单选择**自适应文本长度**，可按当前阅读位置附近的句子调整窗口宽度，并把窗口保持在当前显示器工作区内。
- **多显示器原生支持**：支持主副屏幕、不同 DPI 与跨屏虚拟坐标，在副显示器上拉伸或移动窗口时稳固跟手，绝无漂移或位置跳变。

### 5. 💬 专属小说阅读体验（用户消息过滤）
- **仅看 AI 对白与小说正文（默认开启）**：阅读时自动跳过所有用户输入楼层，新消息接收、读完自动进入下一楼、或翻楼查阅时，均直接展示连续的 AI 角色回复与正文描写。
- **自由切换显示**：可在右键菜单或设置面板中随时一键开关“显示用户消息”，兼顾纯小说沉浸与对话复盘。

### 6. 🛡️ 智能白名单正文提取 + 思考黑名单彻底剥离
- 名单可直接填写标签名，如 `game`。粘贴 `<game>` 或 `&lt;game&gt;` 时会自动归一化。正文中的多层转义和数字实体也会在匹配前解码。
- **白名单正文容器提取**：优先提取包裹在 `<content>`、`<response>`、`<dialogue>`、`<story>`、`<正文>` 等标签内的纯净正文，外层的复杂选项、元数据或变量更新自动隔离；若未检测到容器标签则自动读取全文。
- **全语法格式黑名单剥离**：彻底清除黑名单标签及其内部文本，不仅全面支持标准闭合标签（`<think>...</think>`、`[thought]...[/thought]`），亦完美兼容提示词中常见的单标签与冒号指令（如 `[system: ...]`、`<instruction: ...>`），杜绝指令泄露。

### 7. ⌨️ 双行边看边回 / 单行纯享
- **双行模式（边看边回）**：上行小说正文，下行就地嵌入紧凑回复框，打字按 `Enter` 立即回车发送并自动触发酒馆 AI 续写。
- 编辑回复时，方向键和翻页键保留输入框的编辑行为。桌面桥接断开时，点发送会保留草稿。
- 右键输入框打开**中文标点**，可以插入符号，或开启键入时转换常用标点。开启后可用 `Shift + 9` 和 `Shift + 0` 输入 `（）`。使用中文输入法时，确认候选字的回车会留给输入法。
- 工具条会显示**生成中**、**生成完成**、**生成失败**或**已停止**。结果提示几秒后消失。失败时可点击**重试**，也可用右键菜单或 `Alt + S` 重试。
- 识别到 `<options>`、`<choices>` 或「选项」标题下的列表时，工具条右侧会出现**选项**按钮。把 `options` 加到正文黑名单可以在正文里隐藏选项，仍可通过按钮查看。双行模式下点选会将内容填入草稿，单行模式下会复制到剪贴板。
- **单行模式（极致紧凑）**：仅 30px 高度的超窄纯阅读条，最大程度减少屏幕占用。

### 8. 🕶️ 强韧常驻的一键老板键（Boss Key）
- 遇到同事或老板走近时，按下 **`Esc`** 键：0.1 秒内秒切为 `TypeScript Ready` 或 `webpack compiled successfully` 代码编译状态。
- **全局老板键 `Ctrl+Alt+B`**：`Esc` 只在摸鱼条有焦点时生效（在浏览器里打字就按不到），而这个热键由托盘助手注册，**不管焦点在哪个窗口**都能直接切/退伪装；托盘右键菜单里也有「老板键（伪装 / 恢复）」。热键走本地 WebSocket 通道（用 `thief_bar_bridge.token` 认证），无需点条、不会抢焦点。
- **16 套伪装风格已并入「主题」（`Alt+T` 循环切换）**：右键菜单 `主题 · <当前皮>` 里按「开发 / 办公 / 影音 / 系统」四组收起，`⚙️ 设置` 面板的「主题（伪装风格）」下拉同步；选中即记进 `bossStyle`，伪装时按 `Esc` 就是这副样子。

  **开发工具**（7）— VS Code · TypeScript（默认，`TypeScript 5.4.5 UTF-8 Ln 142, Col 8 Ready`）、Git · 仓库状态（`Your branch is ahead of 'origin/…' by 2 commits.`）、Maven · Java 构建（`[INFO] BUILD SUCCESS  Tests run: 214`）、npm · 单元测试（`PASS service.spec.ts  42 passed, 42 total`）、Docker · 容器编排（`[+] Running 6/6  Container app-api-1 Started`）、Python · pytest（`128 passed in 6.42s`）、CI · 流水线（`Pipeline #4821  build ✓  test ✓  deploy in progress`）

  **办公软件**（2）— Word · 文档状态（`页面 3/7 ｜ 字数 1,284   字符数 1,102   段落 46 ｜ 中文(中国)`）、Excel · 表格状态（`Sheet1 ｜ 平均值: 42.7    计数: 128    求和: 5,465 ｜ 就绪`）

  **影音播放**（2）— 音乐 · 桌面歌词（`♪ [00:42.18] 窗外的麻雀 在电线杆上多嘴… ｜ 01:42 / 04:51`）、播放器 · 迷你进度（`▶ 七里香 - 周杰伦 ｜ 38%`）

  **系统工具**（5）— 系统 · 性能监控（**真实采样**：`CPU 24% ｜ 内存 65%  GPU 2%  进程 517 ｜ ↓1.2M ↑221K`，CPU/内存/GPU/磁盘/网速/进程数都来自系统，每秒刷新）、下载 · 进度条（`ubuntu-24.04.iso  8.4 MB/s  剩余 00:12:31 ｜ 62%`）、网盘 · 同步状态（`☁ 已同步 2,431 个文件 ｜ 100%`）、行情 · 股票滚动（`上证 3,142.68 +0.42%   深证 9,864.21 -0.18%`）、桌面 · 时钟天气（**时间日期是真的**，只有天气是固定文案：`15:12 ｜ 周四 11/26 多云 18°C 湿度 62% ｜ 北京`）

  每条风格连**输入框占位文案**都配套（例如歌词皮是 `▶ 七里香 - 周杰伦  单曲循环`，下载皮是 `目标文件夹: D:\Downloads  同时下载 1 个任务`），进出伪装时草稿照样保留。风格与 `autoBossSec` 一起存进 `thief_bar_config.json`（`bossStyle`）。
- **防误触常驻机制**：处于伪装状态时屏蔽点击翻句与滚轮动作，移动窗口不解除伪装，**必须再次显式按下 `Esc`** 才会安全退出伪装返回阅读。
- **无操作自动伪装（时间滑块）**：右键菜单 `无操作自动伪装 → 时间滑块...`，或在 `⚙️ 设置` 面板里拖动滑块（0 ~ 600 秒，0 = 关闭）。判定同时看两条时钟——**摸鱼条自身有多久没交互** 与 **Windows 全系统最后一次键鼠输入**，**任一**达到设定时长就触发（取较大者；若取较小值，鼠标随便路过一次就会把倒计时清零，导致永远不触发）。鼠标正压在摸鱼条上视为你在看，不触发；设置面板 / 滑块窗口开着时也不触发。到点后**静默**切入代码伪装，屏幕上不弹任何提示；回来按 `Esc` 即恢复并按当前时刻重新计时。菜单里的级联项会实时显示「还剩 Ns / 待触发 / 已挂起」，`自动伪装诊断...` 还能看到两条时钟与判定状态的原始数值。

## 🚀 极速上手

### 第一步：启动桌面摸鱼条（阅读界面）
1. 双击运行项目目录下的 **`start_desktop.bat`**（或在终端运行 `python thief_desktop_bar.py`）；
2. 屏幕底部即出现摸鱼条窗口，零额外依赖、开箱即用；
3. **右键点击任意处**：呼出深色功能菜单，一键切换极简模式、单双行布局、自动阅读、贴边隐藏、透明度与黑白名单；
4. **左键点击文字**或**鼠标滚轮**即可整段分屏翻阅；双行模式下直接在下方输入框打字按 `Enter` 就地回复。

> 单实例保护：重复启动会自动退出，不会出现两条摸鱼条互抢消息。

### 第二步：导入网页桥接脚本（过滤与同步）
1. 打开 SillyTavern，进入 **酒馆助手（Tavern Helper）** -> **脚本管理**；
2. 点击 **“导入脚本”**，选择项目中的 **`st-thief-book.json`** 导入并启用；
3. **魔法棒（扩展）菜单**（输入框左上方 wand 图标）出现 **摸鱼条** 条目，点击打开设置面板；
4. 按上文「首次配对」勾选启用桌面同步并填入桥接密钥，桌面端随即开始实时接收酒馆消息。

> 桌面同步**默认关闭**：纯网页使用不发起任何连接、控制台零报错；勾选启用后自动连接/重连，桌面端启动即自动连上，不用时取消勾选即恢复安静。

## 💡 使用小贴士

1. **更隐蔽的摆放推荐**：
   - 开启 **极简模式** 后，将摸鱼条长度拉长至接近屏幕底边宽度，贴近 Windows 任务栏上方放置，外观与系统状态提示无异。
   - 适当将透明度设置为 **70% 或 80%**，背景融入当前工作软件窗口（如 IDE 或浏览器），既清晰易读又极大降低侧边被窥视风险。
   - 开启 **贴边自动隐藏** 后把窗口拖到屏幕边缘，平时只露 3px 细条，鼠标轻碰边缘即滑出，隐蔽性拉满。
2. **沉浸式追更**：开启 **自动阅读（每 5 秒）**，AI 生成时自动暂停、生成结束继续翻屏，配合 **阅读位置记忆**，重启后从上次那一屏接着读。
3. **提示词与思考过程过滤**：
   - 若使用的模型具有 DeepSeek 或 CoT 思考链，摸鱼条已内置预设过滤 `<think>`, `<thought>`, `<cot>`, `[system: ...]` 等思考过程。如果使用了其他自定义标签，随时打开 **右键 -> ⚙️ 设置**（或网页端魔法棒菜单 **摸鱼条**）将标签名称填入黑名单即可彻底过滤。
4. **远程酒馆**：桌面端默认仅接受本机来源连接；若酒馆部署在远端，右键菜单 **远程酒馆来源白名单…** 中添加其 Origin 后方可桥接。
