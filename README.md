# ST-Thief-Book: 酒馆助手（Tavern Helper）隐蔽摸鱼阅读与回复工具 (v2.9 高度恒定锁定、单行顺延阅读与双显示器防漂移版)

> **仿 VS Code 著名摸鱼插件「Thief-Book」设计。**
> 
> 专为办公室、宿舍、公开场合打造的 SillyTavern（酒馆）极致隐蔽交互工具。将 AI 长篇回复切片为小说单句，以 **参考图极简纯文本条** 或 **VS Code 底部状态栏** 呈现，支持**鼠标边缘按住直接拖拽缩放长度**、**多行自动折行与窗口高度自适应撑开（绝不裁切截断）**、**一键自动适应文字长度 (Auto-fit)**、**快捷键/滚轮/点击逐句阅读**、**单行/双行自由切换（双行就地输入回车即发）**、**全功能右键菜单（切换极简、切换楼层、窗口长度与透明度微调滑块）**、**长句自动折行全显**、**正文白名单容器提取 + 思考黑名单彻底剔除**与**一键老板键秒切代码伪装**，彻底脱离显眼网页！

## 🌟 核心升级与特性 (v2.9 最新版)

1. **📏 显示条高度恒定锁定（严禁向下撑大窗口，保持极致隐蔽）**：
   - **高度绝对不变**：极简单行模式恒为 **30px**、极简双行模式恒为 **56px**、标准单行模式恒为 **36px**、标准双行模式恒为 **68px**；
   - **拒绝多行弹窗**：文字严格单行展示（`wraplength=0`），绝不向下撑高变为显眼的多行大窗口。

2. **📖 智能单行顺延分页（“在下一行显示”，100% 不裁剪未显示文字）**：
   - **像素级自适应切片**：根据当前窗口长度与字体像素测量，当遇到超长文字时，自动在自然停顿标点处拆分成单行子行（如 `[子行1, 子行2...]`）；
   - **丝滑逐行推进**：第一步展示能完全容纳的子行 1；按 `→` / `K` 或点击文字时，**直接在当前单行条中顺延显示未显示的剩余文字（子行 2）**，并在右侧提示当前顺延进度（如 `3/84 (1/2)`）；
   - **读完全文自然推进**：当前句所有顺延子行阅读完毕后，再次点击自然过渡到下一句，绝不跳段、绝不丢字。

3. **🖥️ 双显示器/多屏幕原生支持（彻底根治拉伸瞬移漂移 Bug）**：
   - **跨屏坐标完全自由**：彻底解除了单屏分辨率限制，无论窗口拖到左副屏（负 X 坐标）、右副屏（超大 X 坐标）还是不同 DPI 的外接显示器上；
   - **拉伸缩放不跳屏**：按住边缘调整长度或拖动窗口时，窗口稳稳固定在当前显示器中，绝不发生跳回主屏或位置漂移。

4. **↔️ 窗口长度自由拖拽拉伸（鼠标两端按住即拉，跟手流畅）**：
   - **双侧边缘智能感应**：鼠标悬停在摸鱼条的**左边缘或右边缘**（12px 感应区），光标自动变为水平双向缩放箭头 `↔`；
   - **拉长/缩短实时重排**：按住拖动拉长窗口时，每行容纳字数增多、顺延步数自动合并；缩短窗口时自动切分顺延，全程高度恒定不变；
   - **自动持久化记忆**：松开鼠标后自动保存当前宽度，下次启动自动记住。

3. **✨ 智能一键文字长度自适应（Auto-fit）与丰富预设档位**：
   - **一键匹配最佳长度**：按下快捷键 **`Ctrl + ↑`** 或右键菜单选择 **“✨ 自动适应文字长短”**，系统根据当前句子的字体真实像素宽度，自动为窗口匹配最佳长度，短句紧凑精致，长句舒展易读；
   - **快捷键无级微调**：按 **`Ctrl + →`** 加长 100px，按 **`Ctrl + ←`** 缩短 100px；
   - **右键专属菜单**：右键菜单新增 **`📏 窗口长度`** 子菜单，包含常用档位（480px 极窄、680px 紧凑、860px 标准、1080px 宽屏、1360px 超宽）以及**原生像素滑块微调弹窗**。

4. **✨ 参考图极简模式（Minimal Mode，最纯粹的隐蔽摸鱼形态）**：
   - **极致干净**：完全按照参考设计图规范重构，界面**只显示文字和背景**，移除/隐藏所有 Git 分支徽章、楼层胶囊、阅读进度数字、角色名标签和所有多余按钮。
   - **单行模式（30px 极窄）**：纯文字条，极度紧凑隐蔽，放在屏幕边缘或任务栏上方就像系统日志或状态提醒。
   - **双行模式（56px 边看边回）**：上行小说纯文字，下行紧贴单行回复输入框（隐藏多余的前缀与发送按钮），直接打字按 `Enter` 立即发送并触发 AI 续写。
   - **鼠标操作分离**：
     - **鼠标单击文字**：直接阅读下一句；
     - **鼠标拖拽中间**：移动摸鱼条到屏幕任意位置（内置 3px 智能防抖位移检测，点击翻句与按住拖拽完美兼容）；
     - **鼠标拖拽边缘**：拉伸/缩短摸鱼条长度；
     - **鼠标右键点击任意处**：一键呼出全功能深色上下文菜单。

5. **📖 右键全功能上下文菜单（极简模式下的全能遥控器）**：
   - 因为极简模式隐藏了界面多余控件，所有控制全部集成在**右键上下文菜单**中：
     - `✨ 极简模式 [✓ 已开启 / 未开启]`：随时一键在“参考图极简形态”与“VS Code 状态栏形态”之间切换；
     - `↕ 布局切换`：一键在「双行边看边回」与「单行极窄纯正文」之间切换；
     - `📏 窗口长度`：自动适应长短、加长/缩短、预设档位与滑块精确微调；
     - `📖 当前楼层状态`：菜单直接展示当前阅读状态（如 `📖 当前楼层: #42 (句 3/84)`），点击可呼出跳转面板；
     - `▲ 上一楼 (PageUp)` / `▼ 下一楼 (PageDown)` / `⏮ 首楼 (#0)`：右键直接切楼层；
     - `🔢 快速输入楼层跳转...`：快速数字直达任意历史楼层；
     - `‹ 上一句 (←/J)` / `› 下一句 (→/K)` / `⟲ 重卷 (Alt+S)` / `⏹ 中止 (Alt+X)`；
     - `↩ 换行模式`：自动折行全显（绝不截断） / 强制单行；
     - `🌓 窗口透明度多档预设 + 原生滑块微调`；
     - `🕶️ 一键老板键 (Esc)`；
     - `⚙️ 白名单容器与思考黑名单设置...`。

6. **🎯 独创【白名单正文提取 + 黑名单思考剔除】双引擎架构**：
   - **白名单容器正文提取（默认开启）**：若回复含有 `<content>`, `<output>`, `<response>`, `<dialogue>`, `<story>`, `<reply>`, `<text>`, `<正文>` 等标签，仅截取白名单容器内的精彩正文，外层的复杂元数据、分支选项与变量更新全部自动隔离！
   - **智能安全降级**：若角色卡并未使用任何容器标签，则自动安全回退为读取全文，绝不丢字！
   - **黑名单思考块彻底清除**：在提取的正文中，彻底清除黑名单内的思考与系统标签（如 `<think>`, `<think_fox~>`, `<cot>`, `<thought>`, `<status>`, `<bbi_image>`, `<fox_hugou>`, `<fox_selc>`, `<fox_tip>`, `<so_seq>`, `<details>`）；非黑名单标签仅剥除尖括号保留纯文字。

7. **一键老板键（Boss Key）秒切伪装**：
   - 遇到同事或老板走近，按下 `Esc` 键：0.1 秒内秒切为 `TypeScript 5.4.5 Ready` 与 `webpack compiled successfully` 纯代码日志，再次按下秒切回当前小说进度。

## 🚀 极速上手

### 方式一：Python 原生桌面端摸鱼（极度推荐，完全符合参考图）
1. 双击运行目录下的 **`start_desktop.bat`**（或执行 `python thief_desktop_bar.py`）；
2. 屏幕底部将出现置顶的摸鱼窗口，**鼠标右键点击任意处**，点击第一项 **“✨ 极简模式”**；
3. 状态栏瞬间变为纯黑/深灰背景条，只显示纯小说文字；
4. **调整长度**：鼠标移到摸鱼条最左边或最右边，按住拖动即可拉长或缩短；或者按 `Ctrl + ↑` 自动根据当前句子匹配长度；
5. 鼠标左键点击文字直接翻句，按住中间随意拖拽移动位置，右键可随时切换楼层、单双行或微调透明度；
6. 如果使用双行模式，下方输入框输入文字按 `Enter` 直接发送给酒馆 AI！

### 方式二：浏览器 Web 端摸鱼（酒馆助手插件）
1. 打开 SillyTavern，进入 **酒馆助手（Tavern Helper）** -> **脚本管理**；
2. 点击 **“导入脚本”**，选择项目中的 **`st-thief-book.json`** 导入并启用；
3. 酒馆主界面右下角将出现常驻的 **`🐟 Thief摸鱼条 ⚙️`** 悬浮胶囊（也可按 `Alt + M`）；
4. 点击悬浮胶囊即可打开置顶画中画/小窗，在小窗内右键即可开启极简模式并调节尺寸。
