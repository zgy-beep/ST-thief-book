# ST-Thief-Book: 酒馆助手（Tavern Helper）隐蔽摸鱼阅读与回复工具

> **仿 VS Code 著名摸鱼插件「Thief-Book」设计。**
>
> 专为办公室、宿舍及公开场合打造的 SillyTavern（酒馆）极致隐蔽交互工具。将 AI 生成的长篇回复切片为小说单句，以**极简纯文本条**或 **VS Code 底部状态栏**形式呈现。支持鼠标边缘拖拽缩放、单行顺延阅读、智能长度自适应、边看边回、正文白名单提取与思考黑名单剥离、一键老板键秒切代码伪装，助你从容优雅地享受阅读！

---

## ✨ 核心特性

### 1. 🕶️ 极致隐蔽的摸鱼形态
- **参考图极简形态（Minimal Mode）**：界面纯净无冗余，仅保留正文文字与极简深色背景，移除所有徽章与多余按钮，隐藏在屏幕边缘或任务栏如同系统提示。
- **VS Code 状态栏形态**：高度仿真的开发工具状态栏设计，自带 Git 分支、楼层胶囊与进度展示，与日常编程工作区天衣无缝融合。
- **多款专业主题**：内置 `VS Code 深色`、`经典蓝条`、`终端黑客绿` 等预设风格，支持 15%~100% 透明度无级微调。

### 2. 📏 恒定高度锁定与单行顺延阅读
- **窗口高度绝对锁定**：单行模式固定 30px/36px，双行模式固定 56px/68px，无论文字多长均绝不向下撑大窗口，杜绝大弹窗暴露风险。
- **单行顺延分页阅读**：当遇到超长文字时，系统会自动在标点处切分为单行小段。点击或按快捷键翻句时，**文字直接在单行条内平滑顺延至下一段（如 `3/84 (1/2)`）**，读完当前句所有内容后自然过渡到下一句，100% 不裁切、不截断、不丢字。

### 3. ↔️ 自由拉伸、Auto-fit 与多屏幕原生支持
- **边缘鼠标直接拖拽**：鼠标悬停在摸鱼条左/右边缘即可拖拽拉长或缩短窗口，文字实时重新排版，宽度自动持久化保存。
- **智能 Auto-fit（一键适应长短）**：按下 `Ctrl + ↑` 或右键菜单选择“自动适应文字长短”，系统会根据当前句子的实际字数与像素宽度，自动为窗口匹配最舒适的长度。
- **多显示器原生支持**：支持主副屏幕、不同 DPI 与跨屏虚拟坐标，在副显示器上拉伸或移动窗口时稳固跟手，绝无漂移或位置跳变。

### 4. 💬 专属小说阅读体验（用户消息过滤）
- **仅看 AI 对白与小说正文（默认开启）**：阅读时自动跳过所有用户输入楼层，新消息接收、读完自动进入下一楼、或翻楼查阅时，均直接展示连续的 AI 角色回复与正文描写。
- **自由切换显示**：可在右键菜单或设置面板中随时一键开关“显示用户消息”，兼顾纯小说沉浸与对话复盘。

### 5. 🛡️ 智能白名单正文提取 + 思考黑名单彻底剥离
- **白名单正文容器提取**：优先提取包裹在 `<content>`、`<response>`、`<dialogue>`、`<story>`、`<正文>` 等标签内的纯净正文，外层的复杂选项、元数据或变量更新自动隔离；若未检测到容器标签则自动读取全文。
- **全语法格式黑名单剥离**：彻底清除黑名单标签及其内部文本，不仅全面支持标准闭合标签（`<think>...</think>`、`[thought]...[/thought]`），亦完美兼容提示词中常见的单标签与冒号指令（如 `[system: ...]`、`<instruction: ...>`），杜绝指令泄露。

### 6. ⌨️ 双行边看边回 / 单行纯享
- **双行模式（边看边回）**：上行小说正文，下行就地嵌入紧凑回复框，打字按 `Enter` 立即回车发送并自动触发酒馆 AI 续写。
- **单行模式（极致紧凑）**：仅 30px 高度的超窄纯阅读条，最大程度减少屏幕占用。

### 7. 🕶️ 强韧常驻的一键老板键（Boss Key）
- 遇到同事或老板走近时，按下 **`Esc`** 键：0.1 秒内秒切为 `TypeScript Ready` 或 `webpack compiled successfully` 代码编译状态。
- **防误触常驻机制**：处于伪装状态时屏蔽点击翻句与滚轮动作，移动窗口不解除伪装，**必须再次显式按下 `Esc`** 才会安全退出伪装返回阅读。

## 🚀 极速上手

### 方式一：Python 原生桌面端（强烈推荐）
> 零额外依赖，开箱即用，独立的桌面置顶悬浮条。

1. 双击运行项目目录下的 **`start_desktop.bat`**（或在终端运行 `python thief_desktop_bar.py`）；
2. 屏幕底部即出现摸鱼条窗口；
3. **右键点击任意处**：可呼出深色功能菜单，一键切换极简模式、单双行布局、调整透明度与黑白名单；
4. **左键点击文字**或**鼠标滚轮**即可顺畅翻句阅读；
5. 在双行模式下，直接在下方输入框打字并按 `Enter` 即可就地发送回复给酒馆。

### 方式二：酒馆助手 Web 插件端
1. 打开 SillyTavern，进入 **酒馆助手（Tavern Helper）** -> **脚本管理**；
2. 点击 **“导入脚本”**，选择项目中的 **`st-thief-book.json`** 导入并启用；
3. 酒馆主页右下角将出现常驻的 **`🐟 Thief摸鱼条 ⚙️`** 胶囊入口（也可通过快捷键 `Alt + M` 开启）；
4. 打开独立画中画小窗，享受与桌面端同等的功能与配置。

## 📁 项目文件架构

| 文件名 | 作用说明 |
| :--- | :--- |
| **`st-thief-book.json`** | **酒馆一键导入脚本包**：直接导入酒馆助手即可完整使用 Web 端摸鱼条 |
| **`st-thief-book.js`** | **Web 端核心脚本源码**：负责界面渲染、自适应排版、黑白名单过滤与 WebSocket 桥接 |
| **`thief_desktop_bar.py`** | **原生桌面端客户端**：轻量、无外部依赖的置顶透明状态栏程序，支持与酒馆实时同步 |
| **`start_desktop.bat`** | **Windows 便捷启动脚本**：双击即可启动 Python 桌面端客户端 |
| **`thief_bar_config.json`** | **桌面端本地配置文件**：保存窗口尺寸、透明度、主题及过滤配置项 |

## 💡 使用小贴士

1. **更隐蔽的摆放推荐**：
   - 开启 **极简模式** 后，将摸鱼条长度拉长至接近屏幕底边宽度，贴近 Windows 任务栏上方放置，外观与系统状态提示无异。
   - 适当将透明度设置为 **70% 或 80%**，背景融入当前工作软件窗口（如 IDE 或浏览器），既清晰易读又极大降低侧边被窥视风险。
2. **提示词与思考过程过滤**：
   - 若使用的模型具有 DeepSeek 或 CoT 思考链，摸鱼条已内置预设过滤 `<think>`, `<thought>`, `<cot>`, `[system: ...]` 等思考过程。如果使用了其他自定义标签，随时打开 **右键 -> ⚙️ 设置** 将标签名称填入黑名单即可彻底过滤。
